# Analog Atlas - Data Attribution & Asset Licenses

## 1. NASA & USGS Planetary Data
- **NASA LRO LOLA Data**: Courtesy of NASA/GSFC/LOLA Science Team. Public Domain / NASA open data policy.
- **NASA Mars MOLA & HRSC Data**: Courtesy of NASA/JPL/Goddard, ESA/DLR/FU Berlin, and USGS Astrogeology Science Center. Public Domain.
- **NASA Trek Portals**: NASA Solar System Treks Project (JPL/Caltech).

## 2. Terrestrial Topography & Remote Sensing
- **Copernicus DEM**: Produced using Copernicus WorldDEM-30 © DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018 provided under Copernicus open access.
- **USGS 3D Elevation Program (3DEP)**: Public domain U.S. government dataset.
- **WorldClim 2.1**: Free climate data for academic and commercial use (Fick & Hijmans, 2017).

- Built using Three.js (MIT License), Lucide Icons (ISC License), and custom procedural shaders / WebGL materials.
